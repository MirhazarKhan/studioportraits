# Security & Privacy Policy

## 🔒 Absolute Privacy for Subject Photographs
Portrait Generator is engineered with **privacy by design**:
- All raw reference photographs, personal camera dumps, and subject directories are excluded via `.gitignore`.
- Photos placed in `inputs/` remain 100% on your local machine unless you explicitly configure a third-party cloud generation API.
- Prompt Export Mode (`PORTRAIT_PROVIDER=export`) runs completely offline without network requests.

## 🛡️ Responsible & Ethical AI Use
This toolkit is intended for creative artistic portraiture, professional avatar creation, and photographic styling with explicit subject consent.
- **Do not** use this software to generate non-consensual imagery, deepfakes, harassment, or deceptive impersonation.
- Always obtain permission from individuals before processing their biometric likeness or reference photographs.

## Reporting Security Vulnerabilities
If you discover a security vulnerability or accidental exposure issue, please report it via GitHub Security Advisories or contact the repository maintainers directly.
